# Notice

## Scope

This repository publishes **architecture patterns**: multi-provider
scheduling, credential/token pools, quota management, session brokering,
and educational proxy/worker pool composition.

## Out of scope

- Web crawlers and scrapers
- Browser fingerprint / anti-detect automation
- Reverse-engineered private application protocols
- Hard-coded production secrets or customer data

## Proxies

Any proxy-related code or docs are for **learning and discussion only**,
not for commercial deployment guidance. Users are responsible for complying
with applicable law and third-party terms.
